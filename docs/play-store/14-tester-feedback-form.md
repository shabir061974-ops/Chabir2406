# Faiha Store — Tester Feedback Form (bilingual)

Use this as a **Google Form** (recommended — responses collect automatically and give you real
data for the Production Access application) or send it as a WhatsApp/email questionnaire.

> **Why this matters:** Google's Production Access application asks *"What feedback did you
> receive and how did you apply it?"* Real, specific answers get approved; vague ones get
> refused. This form gives you evidence to quote.

---

## Recommended Google Form setup

**Form title:** Faiha Store — Tester Feedback / ملاحظات مختبري متجر الفيحاء
**Description:**
> Thank you for testing the Faiha Store app! Please answer a few short questions. It takes 3 minutes.
> شكراً لتجربتك تطبيق متجر الفيحاء! يرجى الإجابة على بعض الأسئلة القصيرة. تستغرق ٣ دقائق.

Settings: collect email address **optional**, allow one response per person, accept responses
for the whole 14-day window.

## Questions

**1. What Android phone are you using?** *(short answer)*
ما نوع هاتفك الأندرويد؟

**2. Which language did you use the app in?** *(multiple choice)*
بأي لغة استخدمت التطبيق؟
- English
- العربية / Arabic

### Section 2 — Did it work?

**3. Were you able to install the app successfully?** *(multiple choice)*
هل تمكنت من تثبيت التطبيق بنجاح؟
- Yes, no problems / نعم، بدون مشاكل
- Yes, but it took a few tries / نعم، لكن بعد عدة محاولات
- No / لا

**4. Which of these did you try?** *(checkboxes — tick all)*
ما الذي جربته؟
- [ ] Browsed products / تصفحت المنتجات
- [ ] Searched for a product / بحثت عن منتج
- [ ] Viewed a product's details / اطلعت على تفاصيل منتج
- [ ] Added something to the cart / أضفت منتجاً إلى السلة
- [ ] Applied a coupon code / استخدمت كود خصم
- [ ] Created an account / أنشأت حساباً
- [ ] Placed an order (cash on delivery) / قدمت طلباً (الدفع عند الاستلام)
- [ ] Tracked an order / تتبعت طلباً
- [ ] Switched between English and Arabic / بدلت بين الإنجليزية والعربية

**5. Did anything not work, look wrong, or confuse you?** *(paragraph)*
هل واجهت شيئاً لا يعمل أو يبدو خاطئاً أو غير واضح؟
> *If yes, please say which screen and what happened.*
> *إذا نعم، يرجى ذكر الشاشة وما حدث.*

**6. Did the app ever crash, freeze, or fail to load?** *(multiple choice)*
هل تعطل التطبيق أو توقف أو فشل في التحميل؟
- Never / أبداً
- Once / مرة واحدة
- A few times / عدة مرات
- Often / كثيراً

## How to use the results

Keep a simple running log so you can answer Google honestly:

| # | Tester | Issue reported | Severity | Action taken |
|---|---|---|---|---|
| 1 | | | Blocker / Minor / Cosmetic | Fixed / Won't fix / Noted |
| 2 | | | | |

**Then quote it in the Production Access answer**, e.g.:
> *"14 testers completed our feedback form. 13 installed without any issue; one needed a second
> attempt because the test link had not propagated yet. Testers reported [X]; we responded by
> [Y]. No crashes were reported. Average ease-of-use score was [N]/5."*

⚠️ Only state what actually happened — reviewers can cross-check against your test data.
